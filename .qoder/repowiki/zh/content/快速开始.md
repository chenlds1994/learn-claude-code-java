## 简介
本指南面向首次接触 Learn Claude Code Java 项目的用户，目标是帮助你在最短时间内完成环境准备、依赖安装、配置设置与前后端启动，体验"大模型决策 + 本地工具执行"的 Agent 闭环。项目后端基于 Java 17 与 Maven，前端为 Next.js 应用；后端通过 Anthropic-compatible 接口调用模型，支持自定义 Base URL 与 API Key。

## 环境准备

### 必需软件
- **Java 17**：项目编译和运行需要 Java 17 或更高版本
- **Maven**：用于构建和管理 Java 项目依赖
- **Node.js**（推荐 LTS 版本）：用于前端开发服务器

```bash
# 检查 Java 版本
```

## 配置设置

### .env 文件配置
在项目根目录创建 `.env` 文件，配置以下环境变量：

#### 基础配置示例
```env
# API Key（必填）
ANTHROPIC_API_KEY=your_api_key_here

# 模型 ID（必填）
MODEL_ID=glm-4.7

# Base URL（可选，默认使用 Anthropic 官方端点）
ANTHROPIC_BASE_URL=https://open.bigmodel.cn/api/anthropic
```

#### BigModel 配置示例
本项目已预配置了 BigModel 的 Anthropic 兼容端点：
```env
# BigModel 的 Anthropic 兼容端点
ANTHROPIC_API_KEY=your_bigmodel_api_key
MODEL_ID=glm-4.7
ANTHROPIC_BASE_URL=https://open.bigmodel.cn/api/anthropic
```

#### 其他兼容服务配置
你也可以使用其他支持 Anthropic 协议的第三方服务：
```env
# OpenRouter 示例
ANTHROPIC_API_KEY=your_openrouter_key
MODEL_ID=anthropic/claude-3-opus-20240229
ANTHROPIC_BASE_URL=https://openrouter.ai/api/v1

# 本地部署示例
ANTHROPIC_API_KEY=local_key
MODEL_ID=llama-3-70b
ANTHROPIC_BASE_URL=http://localhost:8080
```

### 环境变量优先级
系统环境变量优先于 `.env` 中的同名变量，便于在 CI 或 IDE 运行配置中覆盖本地值。

## 常见问题与故障排除

### 环境变量问题
**问题**：启动时报缺少环境变量错误
**解决方案**：
- 确认 `.env` 文件位于项目根目录
- 检查 `MODEL_ID` 是否已正确配置且不为空
- 如果使用系统环境变量，确保名称完全匹配

### 模型调用失败
**问题**：API 调用返回错误或超时
**解决方案**：
- 检查 `ANTHROPIC_API_KEY` 是否正确配置
- 确认 `ANTHROPIC_BASE_URL` 指向可用的兼容端点
- 查看控制台输出的 HTTP 状态码与响应体，定位服务端错误
- 对于 BigModel 端点，确认 API Key 有效且额度充足

### 网络连接问题
**问题**：网络超时或连接中断
**解决方案**：
- 检查网络连通性与代理设置
- 适当调整超时策略或服务端可用性
- 确认防火墙未阻止对目标端点的访问

### 前端无法访问
**问题**：浏览器无法访问前端页面
**解决方案**：
- 确认端口 3000 未被占用
- 重新执行 `npm install` 与 `npm run dev`
- 检查浏览器控制台是否有 JavaScript 错误

### 中文编码问题
**问题**：输出中文显示乱码
**解决方案**：
- 后端构建插件已设置 UTF-8 相关系统属性
- 确保 IDE 与终端也使用 UTF-8 编码
- Windows 用户可在命令行执行 `chcp 65001` 切换编码
