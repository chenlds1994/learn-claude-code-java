- 新增 agent 版本需在 `LEARNING_PATH`、`VERSION_META`、`data/scenarios`、`data/annotations`、`components/visualizations` 以及可选的 `docs/{en,zh,ja}` 中同步注册，保持编号 s01–s12 的一致性。
- 页面组件作为 Server Component 负责组装数据与布局，交互逻辑下沉到同目录下的 `client.tsx` 客户端组件，通过 props 传递版本、diff、source 等数据。
- 可视化模块统一以 `sNN-*.tsx` 命名并按版本号在 `visualizations/index.tsx` 的 lazy 映射表中注册，由 `SessionVisualization` 根据 version 动态懒加载。
- 文案通过 `useTranslations(namespace)` 获取，namespace 对应 `i18n/messages/*.json` 中的顶层键（如 version、sessions、layer_labels、viz），缺失键回退为 key 本身。
- 静态资源与主题色通过 Tailwind 自定义 CSS 变量（如 `--color-bg`、`--color-text`）在 `globals.css` 中声明，组件中以 `bg-[var(--color-bg)]` 形式引用以支持 dark mode。
- Python 源码的结构化信息（类、函数、工具名、LOC）不硬编码，而是由 `extract-content.ts` 在构建期正则解析生成，前端只消费生成的 JSON 数据。
