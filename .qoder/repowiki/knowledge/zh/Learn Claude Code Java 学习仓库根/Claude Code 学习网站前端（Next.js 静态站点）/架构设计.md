采用 Next.js 16 App Router + `output: 'export'` 纯静态导出部署到 Vercel。
- 路由层：`src/app/[locale]/layout.tsx` 提供 I18nProvider、Header 与全局样式；`(learn)` 路由组配合 `Sidebar` 构成学习区布局；`[version]` 动态路由加载具体 agent 版本页面，并通过 `generateStaticParams` 预生成 LEARNING_PATH 中所有版本。
- 数据层：`scripts/extract-content.ts` 在 `predev`/`prebuild` 阶段扫描仓库根 `agents/` 下的 Python 源码与 `docs/{en,zh,ja}/` 下的 Markdown，解析类、函数、工具名并计算相邻版本 diff，输出到 `src/data/generated/versions.json` 与 `docs.json`；运行时再结合 `data/scenarios/*.json` 与 `data/annotations/*.json` 渲染页面。
- 组件层：按职责分目录——`components/layout`（Header/Sidebar）、`components/ui`（Badge/Card/Tabs 等原子 UI）、`components/diff`（代码差异展示）、`components/simulator`（Agent 循环模拟器）、`components/visualizations`（每个 session 一个独立可视化，通过 `index.tsx` 中的 `React.lazy` 映射表按需加载）。
- 国际化：`lib/i18n.tsx` 用 React Context 暴露 `useTranslations(namespace)`，服务端通过 `lib/i18n-server.ts` 的 `getTranslations(locale, namespace)` 在 SSR 阶段取对应 JSON 消息文件（`i18n/messages/{en,zh,ja}.json`）。
- 依赖方向：页面 → 组件 → hooks/lib → 静态数据（generated/scenarios/annotations），脚本仅在生产构建前单向读取仓库源码并写入 generated 目录。
