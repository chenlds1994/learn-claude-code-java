根目录通过 `pom.xml` 统一构建 Java 后端（Java 17 + Jackson + dotenv），并以 `src/main/java/com.learnclaudecode.agents` 下的 `S01AgentLoop` ~ `S12WorktreeTaskIsolation` / `SFull` 各入口类作为教学阶段的隔离边界；所有阶段共享 `AppContext` 装配器、`StageConfig` 能力配置、`AgentRuntime` 主循环、`AnthropicClient` 模型调用、`WorkspacePaths` 工作区路径等公共基础设施，从而在同一工程中实现“同一运行时 + 不同能力开关”的渐进式叠加。`skills/` 目录中的每个技能子目录提供 `SKILL.md`，由 `SkillLoader` 在运行时扫描并注入为 Agent 的可装载知识，使代码与外部知识解耦。前端 `web/`（Next.js）作为独立站点与后端并列存放，用于可视化演示各阶段演进。根级 `.env.example`、`README.md`、`.gitignore` 以及 drawio 流程图共同构成项目的运行说明与学习路径。
