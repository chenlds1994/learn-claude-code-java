根模块通过 pom.xml 统一声明 JDK 17、Jackson 2.17.2、dotenv-java 与 JUnit 5 依赖，并以 exec-maven-plugin 固定 UTF-8 编码；src/main/java 下按 agents/background/common/context/mcp/model/skills/tasks/team/tools 等包划分功能域，每个域对应一组单元测试于 src/test/java 同构路径；入口 Main.java 默认委派给 agents/SFull.main(args)，使完整能力版本成为默认运行形态，而 S01~S17 各阶段类可独立作为教学用例被调用。web/ 子目录为独立的 Next.js 站点，通过 data/scenarios 与 data/annotations 下的 JSON 文件消费 Java 侧各阶段输出，形成“Java 后端演示 + 前端可视化”的双端协作结构。
