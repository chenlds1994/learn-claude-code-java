根目录通过 `pom.xml` 定义 Maven 单工程（groupId `com.learnclaudecode`），统一声明 Java 17、Jackson 2.17.2、dotenv-java 3.0.0 与 JUnit 5 依赖，并使用 exec-maven-plugin 配置 UTF-8 编码以便直接运行各阶段入口类；`skills/` 下每个子目录（agent-builder、code-review、mcp-builder、pdf）提供一份 `SKILL.md`，作为 Claude Code 风格的技能知识文件，由运行时 `SkillLoader` 扫描并注入为 Agent 的可装载知识，使外部知识与代码解耦；`.gitignore` 排除构建产物与 IDE/工作区临时目录；`learn-claude-code-tutorial.drawio` 提供学习路径流程图。该模块本身不包含业务源码，而是承载工程的构建配置、忽略规则、可加载技能文档与教程图示，真正的教学代码位于同仓库的 `src/main/java/com.learnclaudecode.agents` 中。
